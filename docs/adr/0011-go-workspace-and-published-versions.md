# ADR-0011: Published versions in `go.mod`, umbrella `go.work` for local development; core v0.6.0

- **Status:** Accepted
- **Date:** 2026-10-05
- **Decided by:** Delegated

## Context

At the umbrella-pinned SHAs, 46 of 97 Go modules failed to build (roadmap validation log): the `core/pkg/tenant` nested module was folded into `core` but consumers still require/replace it; `core v0.5.8` and `jellyfin v0.3.0` tags exist only on the retired Forgejo; some `go.mod` files carry absolute `/home/ender/...` replaces; 84 modules carry sibling `replace ../core` directives (added by `scripts/ensure-go-replaces.sh`), which break standalone CI and are rejected by core's own marketplace source scan.

## Decision

1. Module `go.mod` files require **published tags only** and contain **no filesystem `replace`**.
2. The umbrella provides `go.work` (generated by `scripts/gen-go-work.sh`) for cross-module development and the umbrella CI workspace build. `scripts/ensure-go-replaces.sh` is retired.
3. Release **core `v0.6.0`** (plus nested `pkg/contracts`, `sdk/go/client`, `sdk/go/module` at `v0.6.0`) from `core` `main` on GitHub; `pkg/tenant` is a package of the root module.
4. Bump consumers in dependency order and tag patch releases; pin the umbrella to the new SHAs.
5. Make historical version references resolvable: restore a missing tag at the exact commit when a published `go.sum` hash identifies it (`core v0.5.8` → `d732be6`); otherwise add resolution tags at the `v0.6.0` commit for placeholder versions that were only ever reached through `replace` (details: [TDD §3.2](../architecture/TDD.md#32-chosen-approach)).

## Alternatives

Sibling replaces (status quo; breaks CI and marketplace), monorepo merge (irreversible, contradicts ADR-0004 releases), re-tagging `v0.5.8` at arbitrary content (checksum mismatches with existing `go.sum`; avoided by matching the recorded hash).

## Consequences

- Standalone builds need only `MUXCORE_CI_TOKEN` for private repos.
- Cross-repo changes require tagging the producer before consumers' CI is green standalone; inside the umbrella, `go.work` allows testing first.
- One-time bulk change across ~85 repos (milestone M1).
